# Zfull-GB font

The application expects `zfull_GB.ttf` in this directory. The binary is not
included in the repository.

Run:

```sh
python3 scripts/fetch-font.py
```

Source: <https://cloud.zectrix.com/zfull_GB.ttf>

SHA-256: `2b74d788dd5bfc63d95b55d98b71842c5c0a925d4822bc90f25a18575125b3b3`

The download helper verifies the digest before installing the file. Confirm
that your use complies with the font provider's terms.
